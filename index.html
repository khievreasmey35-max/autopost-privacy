Privacy Policy — AutoPost Cloud

Effective Date: November 27, 2026

1. Overview

AutoPost Cloud is an internal content publishing automation tool used solely by authorized Facebook Page administrators to format, caption, schedule, and publish video content to their own managed Facebook Pages via the Meta Graph API.

2. Information Collected & Used

AutoPost Cloud only accesses Facebook Page IDs, Page names, and Page Access Tokens explicitly authorized by the Page administrator in order to upload, schedule, and manage video posts on those Pages. We do not collect, sell, rent, or share personal data from public Facebook users or visitors.

3. Data Storage & Security

Access tokens are stored solely inside encrypted repository secrets controlled by the account owner and are never shared with third parties.

4. User Data Deletion Instructions

AutoPost Cloud does not store personal user data. Authorized administrators may revoke app access and delete associated tokens at any time via Facebook Settings → Business Integrations by removing AutoPost Cloud, or by deleting the encrypted secrets in their GitHub repository settings.

5. Terms of Service

This tool is provided exclusively for authorized first-party Facebook Page management in compliance with the Meta Platform Terms and Developer Policies.
